# App 设计·团队审查报告（对标 × 取长补短 × 全生命周期）

> 日期：2026-08-16
> 审查对象：[APP-DESIGN.md](../product/APP-DESIGN.md)（a3e5e74 版）
> 审查方法：仓库 2026-08-11 需求侧调研（PLANET-NEEDS-REPORT / OPPORTUNITY-MAP）+ 本次对标复核（Team Pet App、11pets、Petfetti 现状）
> 审查维度：① 有没有对标 ② 取长补短是否到位 ③ 能力服务是否全面 ④ 宠物全生命周期是否覆盖

---

## 审查结论（先行）

1. **方向判定：通过。** Phase 1 的 8 个业务功能恰好落在竞品失血区（11pets 信任崩塌）与竞品盲区（免注册分享、就诊摘要、主人数据所有权）的交集上，与 2026-08-11 需求侧结论一致。
2. **发现缺陷：此前设计只有隐含的全面性，没有显式的能力地图。** 「为宠物提供全生命周期管理」这个承诺没有落成可审查的结构——本次补上北极星能力地图（§三），Phase 1 范围维持 8 功能不变，全面性由地图保证、工期由 Phase 纪律保证。
3. **落地修订 3 项**（已写回 APP-DESIGN.md）：F3 增加紧急医疗授权字段（竞品全空白、成本≈1 个字段）；新增北极星能力地图；本报告入档防团队失忆。

### 1.3 矩阵读法

- **全员都有**的（协作、记录、提醒）：是行业基线不是差异——必须做到 80 分，但别当卖点（31% 宠物 App 已支持多成员，2026-08-11 调研结论）。
- **没人做或做不好**的（免注册分享、就诊摘要、紧急授权、数据主人叙事、纪念）：PLANET 的差异化集中营——恰好是 F6/F7/F8 加本次修订。
- **平台型竞品的结构性弱点**：Rover/THS/PetDesk 的商业模式依赖账号锁定与平台内交易，**抄不了免注册链接**——这是 OPPORTUNITY-MAP 已验证的"竞品做不到"项。

## 三、宠物全生命周期能力地图（北极星）

「为宠物提供全生命周期管理」的显式落法：**每个生命周期阶段必须有归属能力，每个能力必须标注 Phase**。Phase 1 只打验证靶心（多人 × 慢病/就诊交集人群），但地图保证没有阶段被永久遗忘。

| 生命周期阶段 | 能力 | Phase |
|---|---|---|
| 1. 领养/初到 | 第一天入档、来源、绝育信息 | **P1**（F3 档案 + F5 时间线"领养日"事件） |
| 2. 幼年 | 疫苗系列记录 / 社会化笔记 | **P1** 记录；due 结构化+提醒 P2；训练课程 ✗ 不做 |
| 3. 成年日常 | 任务协作、体重、驱虫/牙科 | **P1**（F4+F5） |
| 4. 异常/急病 | 症状速记、紧急医疗授权 | **P1**（F5 + **A5 本次修入**） |
| 5. 慢病/老年 | 用药清单、症状波动、体重趋势、生活质量量表 | 用药+波动 **P1**；趋势图 P2；QoL 量表 P3 |
| 6. 就医 | Vet-ready Summary、跨机构携带 | **P1**（F6+F7）；AI 辅助 P2 |
| 7. 交接/寄养/旅行 | Sitter 只读链接 | **P1**（F7）；寄养专用模板包 P3 |
| 8. 临终/纪念 | 告别册、纪念页、数据赠予 | **P3**（时间线+照片+导出天然支撑，landing 页 Memories 叙事已埋） |
| 横切 | 数据所有权（导出/硬删） | **P1**（F8） |
| 横切 | 多宠家庭 | P2（schema 已预留 pet 独立实体） |
| 横切 | 费用记录/保险理赔材料 | P3 |
| 横切 | OCR 病历导入、语音速记 | P2 |
| 横切 | 实时推送提醒 | P2（P1 用摘要邮件顶） |

**地图结论**：Phase 1 覆盖阶段 1/2(记录)/3/4/5(核心)/6/7 + 数据所有权——正是付费核心（病历管理者 P2 人群）× 留存核心（协同者 P1 人群）的交集；阶段 5 增强、6 增强与阶段 8 构成 Phase 2/3 拼图；全生命周期无永久空洞。

## 五、护城河复核（为什么这些差异守得住）

1. **免注册链接 + 主人数据所有权**：平台型竞品的商业模式（抽佣/账号资产）使其无法跟进——OPPORTUNITY-MAP 已验证"竞品抄不了"。
2. **借力家庭群聊而非对抗**：Share as image + 每日摘要邮件骑在既有行为上，竞品的 App 内闭环反而成为传播阻力。
3. **窗口期是限时资产**：11pets ~2.8★ 与数据焦虑不会永远持续，Team Pet App 尚小但方向正确——差异化叙事（就诊摘要+免注册）要抢在窗口关闭前建立心智。
