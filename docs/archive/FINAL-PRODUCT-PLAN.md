## 一、产品定位（一页纸）

**一句话定位：** PLANET 是宠物世界的随时可交接入口——主人拥有的、跨机构的、免注册可分享的照护记录。

**押注的 persona（交集人群）：** "P2 痛点 + P1 行为"的交集——有老年或慢性病宠物、且多人共养的家庭。具体画像：32-45 岁、英语市场、伴侣或多代家庭共养、宠物 7 岁以上或有慢性病、过去 6 个月内有就诊或临时交接经历。付费核心是这张脸，留存核心也是这张脸。寄养/出差人群不作为独立招募对象，是 Share 模块使用时的副产物。

**我们是谁：**
- 是主人侧的整理工具：5 分钟把分散的记录整理成兽医看得懂的标准化文件
- 是数据所有权的载体：主人拥有完整副本，可随身携带、跨机构流通
- 是零摩擦分享的入口：接收方不注册、不下载、不登录，点链接即看

**我们不是谁：**
- 不是病历管理 App——让给 GreatPetCare（已转型占据，绑定单一医疗体系）
- 不是多人协作 App——让给 Team Pet App（专门做家庭共享 + 实时任务分配）
- 不是平台型竞品——不做双边市场，不要求接收方注册转化为供给方

**核心差异化（诚实结论）：** 剔除所有陷阱和非护城河后，PLANET 真正的结构性机会只有两个，且都基于竞品的商业模式决定它们改不了：

1. **免注册链接查看 + PDF 优先** = "随时可交接入口"定位。Rover / TrustedHousesitters / Pet Watch 全部要求注册才能查看——注册是它们的护城河。PLANET 作为工具型产品没有这个约束。这不是"竞品一个迭代能追上"，是商业模式层面的结构性差异。
2. **11pets 信任崩塌窗口期**（3.3★，12-18 个月窗口）——抢"我的数据不会消失 + 一键生成 PDF"心智。这是机会窗口不是永久护城河，要快。

其他所有方向——多人协作、交接中心、紧急医疗授权、数据所有权叙事——都是辅助。把资源压在这两点上。

## 二、第一阶段交付物（Phase 0，4 周内）

### 唯一发布：Vet Summary PDF 生成器 + 内嵌邀请入口

一箭三雕：
- 交付真实价值（Summary）——解决"卖空气"的信任问题
- 触发多人验证（分享即邀请）——把 PM 要的多人假设验证嵌入分享动作
- 规避法律敞口（交付可用产品）——卖真实可用的 demo，不是空气

### P0 功能清单（精简到必要）

| 功能 | 关键设计 |
|---|---|
| 宠物档案（精简版） | 名称/头像/犬猫/生日/品种/过敏/慢性病/紧急联系人/当前用药/紧急医疗授权字段 |
| **Vet Summary PDF 生成器** | 一键生成 A4 单页或双页，信息层级：①基本信息+体重趋势 → ②当前用药 → ③主诉与近期异常 → ④既往病史 → ⑤驱虫疫苗状态 → ⑥**过敏单独顶部色块标注**。含「本次就诊主诉 / Why now」字段（兽医看摘要第一句想知道"今天为什么来"） |
| **PDF 分享 + 内嵌邀请入口** | 邀请链接只读、可撤销、带品牌 preview、接收方免注册。PDF 末尾固定区域印"Want to see Milo's full care log? Ask [主人名] for a link."触达接收方向主人反向索取，形成自然邀请路径 |
| Demo Pass 付费 | S$5，7 天有效，购买后可抵扣未来会员 |
| 紧急医疗授权字段 | 对齐 TrustedHousesitters 标准（谁被授权在联系不上时做医疗决定），作为 P0 字段保留但不作为营销重点 |

### 用户流程（文字版）


### Demo Pass 机制

- **定价：** S$5 / US$3.99，7 天有效
- **权益：** 可创建 1 只宠物，可交互生成 Vet Summary PDF，可生成 1 个免注册分享链接
- **抵扣：** 7 天内升级为完整会员，Demo Pass 金额全额抵扣
- **目的：** 验证付费意愿 + 法律敞口最低（交付真实可用 demo 而非空气）+ 解决"信任密度不足以支撑预售永久会员"的核心问题
- **退款：** 14 天无理由（EU 合规底线）

## 三、产品原则（综合四份文档）

1. **形态：PDF 优先。** 兽医不会在诊室扫码看第三方 App 链接——他们的时间成本很高。Summary 主形态是可一键生成的 PDF，辅以免注册可分享链接。这是基于真实工作流反推，不是 UI 偏好。
2. **分享：免注册零摩擦。** 接收方不下载、不注册、不登录、不读说明。加载 < 1.5 秒，首屏看到宠物名 + 真实内容，不立刻弹"输入邮箱"。这是 PLANET 唯一零摩擦触点和唯一病毒式增长来源。
3. **数据：主人拥有，可导出。** "PLANET 不持有你的数据，你是 owner。"支持一键导出完整 PDF + 结构化 JSON。显式承诺"数据永不消失"：即使 PLANET 停服，导出功能保留 6 个月。公开数据备份策略。
4. **AI：整理不诊断（但 P0 是人工 + 模板，诚实）。** P0/Phase 1 的 Summary 全部人工 + 模板化，Landing 不暗示 AI 已在工作。AI 在 P1 落地，硬约束输出 JSON schema，来源可追溯，后置关键词过滤"诊断/建议/疑似/确诊"，命中则灰显 + 免责声明。
5. **边界：不做诊断、不做社交、不做电商、不做平台。** 详见第九节。

## 四、验证计划（综合 VALIDATION + 辩论共识）

### 北极星指标

**有效家庭数（Effective Households）** = 过去 14 天内，至少有 2 个成员在同一只宠物下各完成过 1 次照护操作的家庭数。

同时绑定"多人"和"使用"，任何一边塌陷就归零。比"DAU"或"邀请数"更诚实。

### 辅助指标

- 第二位成员激活率（被邀请后 7 天内完成首次操作的比例）—— Go 门槛核心
- Vet Summary 使用率（生成后 30 天内是否真带去就诊/分享给兽医）
- Share 链接接收方打开率（病毒系数分子）
- 单宠协作密度（每只宠物平均活跃成员数，<1.5 说明退化为单人工具）
- PDF 生成到下载转化率

**警惕的虚荣指标：** Landing 访问量、邮箱收集数、社媒互动数、席位售罄速度。这些不证明产品成立。

### Go/No-Go 门槛

**硬门槛（全部满足才 Go）：**
1. 收到 ≥ 10 笔真实付款（全款会员或 Demo Pass）
2. 其中 ≥ 5 个用户 14 天内邀请第二位成员
3. 其中 ≥ 3 个第二位成员完成至少 1 次操作
4. ≥ 3 份 Summary PDF 实际带去就诊（回访确认，兽医反应记录）

**软门槛（满足任一即预警，不直接否决）：**
- 邀请链接打开率 < 40% → 多人故事存疑
- PDF 生成后带去诊室率 < 30% → 核心卖点存疑
- 付费用户 30 天主动打开率 < 30% → 黏性不足
- 第二位成员激活率 < 40% → 邀请链路设计问题

**介于 Go/No-Go 之间：** 收款达标但激活不达标 → 先做 2 周"激活冲刺"（主动联系未邀请第二人的用户访谈阻力），冲刺后达标则 Go，否则转单人路线。

### 验证时间表（30-45 天）

| 阶段 | 时间 | 动作 |
|---|---|---|
| 预热 | 第 1 周 | 修复技术债（超卖竞态等阻塞项）；Landing 放入可交互 vet summary mock demo；价格改 USD 主显示；Terms 写明退款政策；调低 AI 措辞 |
| 发布 | 第 2 周 | Demo Pass 上线；冻结新永久会员售卖；开始导流 |
| 观察 | 第 3-4 周 | 追踪付款、邀请、第二人激活、PDF 生成下载；对未邀请第二人的用户主动访谈 |
| 回访 | 第 5-6 周 | 回访 PDF 是否真带去就诊，兽医反应；汇总 Go/No-Go 决策 |
| 决策 | 第 6 周末 | 满足全部硬门槛 → 进 MVP；部分满足 → 2 周激活冲刺；多人假设证伪 → 转向 |

### No-Go 时的转向方案

**主转向：单人 AI Pet Vet Visit Summary。** 把散落的宠物病历整理成一份可带去看兽医的报告。砍掉多人协作叙事，押注"5 分钟整理 + PDF 优先 + 数据不消失"。已售 100 席永久会员权益保留，但叙事重心从"家庭协作"切到"主人侧整理工具"。

**次转向：** 如果 PDF 生成后没人带去就诊（核心卖点证伪），但免注册分享链接打开率高，则押注"宠物世界的随时可交接入口"纯工具定位，砍掉 Summary，做极简的"宠物信息卡 + 免注册分享"。

## 五、商业模型

### 定价策略（三轨并行）

**轨道 1：Demo Pass（新增，主验证工具）**
- S$5 / US$3.99，7 天有效，可抵扣未来会员
- 目的：验证付费意愿 + 法律敞口最低 + 解决信任密度问题

**轨道 2：已售 100 席永久会员（冻结新售，分层经营）**
- 不推翻已售订单（尊重沉没成本和已付费用户信任）
- **冻结继续售卖新的永久会员**
- 已售 100 席的"永久"权益在条款里设边界：含 24 个月 AI 服务，之后按当时费率续费（规避无限负债）
- 软目标 20 / 硬上限 100，对外讲"前 20 席创始价"，卖满再开放下一批（当前已售部分继续服务，不再新增）

**轨道 3：未来订阅方向（验证后）**
- US$4.99-7.99/月 或 US$39-69/年
- 家庭多成员共享一个订阅（不按人头）
- 多宠物第一年免费，之后每只 +US$2/月
- 人工 Concierge 是付费 add-on（US$19/次病历深度整理），不包含在订阅内——人工成本线性增长，必须在订阅上线前明确边界

### 合规底线（必须立即处理）

1. **退款政策：** 14 天无理由退款（EU 合规底线），写入 Terms，checkout 前显式展示
2. **权益边界：** "核心产品访问权"必须定义清单，永久会员条款写明"含 24 个月 AI 服务，之后按当时费率续费"，购买时显式同意
3. **USD 主显示：** Landing 价格改 USD 主显示，SGD 辅助。美国用户 mental 换算是真实转化摩擦
4. **交付时间表：** 预售必须明确交付时间表（写入 Terms）
5. **AI 措辞调低：** Landing 改为"整理工具"而非"AI 模型"，避免承诺落差和虚假宣传风险
6. **数据合规：** PDPA/GDPR 下宠物数据与可识别自然人关联后受保护，数据最小化、明确隐私政策、提供导出和删除接口

### 从验证到可持续 SaaS 的路径

```
Phase 0（当前）
  Demo Pass 验证付费意愿 + 冻结新永久会员
  ↓ Go 门槛达标
Phase 1（MVP）
  完整 PWA + 订阅上线（US$4.99-7.99/月）
  ↓ 月活家庭 > 50
Phase 2（规模化）
  AI 摘要落地 + 多宠物 + OCR
  ↓ MRR 可覆盖成本
Phase 3（增长）
  11pets 流失用户获客 + 订阅 + 人工 add-on
```

## 六、设计原则

### 视觉 tone

- **配色：** 奶油白底（#FAF7F2）+ 暖灰文字（#3D3936，非纯黑）+ sage green 强调（#7BA88F）。避免亮橙、婴儿粉、卡通黄。
- **字体：** humanist sans（Inter / Source Sans），正文 16px，行高 1.5，段落间距宽松——"呼吸感"就是温暖。
- **两种节奏：** 医疗数据用紧凑间距 + mono 小标签（精确感）；生活化内容用圆润卡片 + 稍大字号（人情味）。
- **焦虑感管理：** 健康异常事件用温和琥珀色边框（不用红色）；避免用红色表示未完成（制造焦虑）。已完成用温润 sage green 而非亮绿。
- **PET 彩蛋：** 只在 onboarding 创建宠物空间时出现一次 wordmark 中 P-E-T 高亮，之后不再出现。

### 关键界面原则

1. **3 tap to summary：** 宠物页 → "Ready for the vet"按钮 → 生成 PDF。焦虑用户认知带宽极窄，遵循三步内到位。
2. **过敏置顶：** 会出命的问题不能埋在长文档里，单独顶部色块标注。
3. **主诉字段：** 「本次就诊主诉 / Why now」必须有——兽医看摘要第一句想知道"今天为什么来"。
4. **驱虫疫苗状态：** 兽医问诊高频项，必须有。
5. **任务状态三重编码：** 颜色 + 形状 + 文字（色盲友好）。待处理 = 空心灰圈，已完成 = 实心填充 + 勾选，跳过 = 虚线圈 + 横线。
6. **Timeline 按重要性排序：** 默认症状 > 用药变更 > 就诊 > 体重 > 照片 > 疫苗，而非纯时间排序。同一天多个微小事件折叠成 "Aug 8 · 5 care logs"。
7. **Today 区分定时 vs 今日：** 定时任务有钟点（08:00 早餐），今日任务无固定时间（chip 列表）。DESIGN.md 的整点时间设计是幻觉。

### 免注册分享页的信任设计

- **加载 < 1.5 秒：** 首屏看到宠物名 + 一句话价值说明，不要 hero 图占满屏
- **品牌 preview：** 微信/iMessage 分享卡片有 PLANET 品牌 + 宠物头像 + "Shared by [主人名]"
- **先展示真实内容：** 落地页先展示真实照护信息，不立刻弹"输入邮箱"
- **可读 URL：** `planet.pet/m/milo/r/x7k2` 而非一长串 token
- **静态倒计时：** "This link expires in 71 hours"——让接收方知道这是临时的、安全的
- **接收方零耐心假设：** 不会下载、不会注册、不会登录、不会读说明

## 七、技术架构

### MVP 技术栈

| 维度 | 方案 | 理由 |
|---|---|---|
| 前端 | Next.js 15 + React 19 + Tailwind 4（继续，不转纯 React PWA） | 现有栈，迁移是纯损失；加 manifest + service worker 即 PWA |
| 状态管理 | React Query + Context | MVP 规模不需要 Redux/Zustand |
| 后端 | Go 单体继续，不微服务 | 7 endpoint → 约 20 endpoint 仍在单体能控范围 |
| 认证 | Email magic link 为主（P0），Google/Apple OAuth 为辅（P1），用 SuperTokens 或 Clerk | 契合"免注册低摩擦"，不自建密码 |
| 实时协作 | SSE 优于 WebSocket | 任务同步低频，SSE 单向推送 + POST 提交，比 WS 简单一个数量级 |
| 多媒体存储 | Cloudflare R2 | 无出口流量费，不自建 |
| AI 摘要（P1） | Claude Haiku / GPT-4o-mini | 单次成本 US$0.001-0.003，延迟 3-8s 可接受 |
| OCR（P1） | LLM vision（GPT-4o / Claude） | 一次调用同时完成 OCR + 结构化抽取 |

| P1 | 结构化日志 | log/slog 替换 fmt.Printf |
| P1 | DB migration 工具 | golang-migrate / goose |
| P2 | main.go 拆包 | handler/store/service/domain，为 20+ endpoint 腾结构 |
| P2 | email 字段应用层加密 | AES-GCM |
| P2 | 基础 CI | go test + go vet + next build |

**修复成本约 2-3 天，是 Phase 0 发布的前置依赖。**

### AI 能力边界落地

1. **Prompt 硬约束：** System prompt 固定，输出 JSON schema，后端校验，不合规降级模板
2. **来源可追溯：** 每条 Summary 记录 `source_model`、`prompt_version`、`input_event_ids`，用户能看到"这个结论来自哪几条原始记录"，一键导出原始数据
3. **后置关键词过滤：** 输出端跑"诊断/建议/疑似/确诊"检测，命中则灰显 + "以上为信息整理，不构成医疗建议"
4. **P0 诚实：** Phase 0 的 Summary 是人工 + 模板，不暗示 AI 已工作

## 八、成功定义

### Phase 0 成功的具体样子

- Demo Pass 卖出 ≥ 10 笔真实付款
- 其中 ≥ 5 个用户 14 天内邀请了第二位照顾者
- 其中 ≥ 3 个第二位成员完成至少 1 次操作
- ≥ 3 份 Summary PDF 实际带去就诊，回访确认兽医反应
- 至少 3 个用户主动反馈"这比我用过的其他工具好用"或类似主动推荐信号
- 技术债全部清偿，可进入 MVP 开发

### Phase 1（MVP）的触发条件

**全部硬门槛达标 + 技术债清偿 → 进入 MVP 开发。** MVP 在 Phase 0 基础上扩展：
- 完整 PWA 登录和宠物档案
- 今日照护任务完整版（P0 只做"今日清单 + 谁做了标记"，跳过/重复/提醒下沉 P1）
- 邀请第二人可写权限（P0 只读验证后放开）
- 健康时间线完整版（六类事件 + 筛选 + 分组折叠）
- AI 摘要（Claude Haiku / GPT-4o-mini）
- 订阅上线（US$4.99-7.99/月）
- 多宠物（顶部头像横滑切换）

### 失败的诚实信号

- **多人假设证伪：** 邀请链接打开率 < 40% 且第二人激活率 < 40% → 转"单人 AI Pet Vet Visit Summary"
- **核心卖点证伪：** PDF 生成后带去诊室率 < 30% → 重新评估 Summary 形态或押注纯免注册分享工具
- **黏性不足：** 付费用户 30 天主动打开率 < 30% → 产品价值未成立，先做激活冲刺再决定
- **信任密度不足：** Landing 1000+ 目标流量后 Demo Pass 转化 < 0.3% → 先改故事和 demo，不开始大规模开发
- **最坏情况：** 多人和 Summary 双双证伪 → 诚实关闭或彻底重定位，不沉没成本谬误

## 九、明确的"不做"清单

### 产品边界

- **AI 诊断 / 风险评级 / 用药建议**——法律风险且违背"整理不诊断"
- **医生账号 / 医生后台**——不做医疗侧产品
- **公开社交 / 点赞 / 评论 / 关注**——不做社交媒体
- **在线问诊 / 电商 / 保险 / 硬件接入**——不延伸到交易和硬件
- **AI 宠物翻译器类噱头**——对标 PetPal 的失败教训
- **原生 iOS 和 Android 同时开发**——PWA 优先

### 战略放弃

- **病历管理赛道硬碰**——让给 GreatPetCare，已转型占据且绑定医疗体系，数据源优势 PLANET 没有
- **多人协作作为核心卖点**——让给 Team Pet App，31% App 已支持，协作是基线不是差异化
- **通用家庭任务管理**——Team Pet App、TaskNest、OneHaus 已占据，红海
- **跨场景交接中心**——疑陷阱，用户每次只面对一个场景，不需要"中心化"。做模板库，不做中心
- **继续售卖新的永久会员**——冻结，已售 100 席继续服务
