# App 隐私（App Privacy）问卷答案 — 照填即可

创建：2026-09-29。**这份问卷 ASC 没有 API，只能在网页填**（`/v1/appDataUsages` 实测 404）。
答案必须与已发布的隐私政策（`www.joinplanet.pet/privacy`）和实际代码一致，否则是 5.1.1 拒审项。
**入口**：ASC → App → App 隐私（App Privacy）→ 开始填写 / 编辑。

---

## 第 1 问：「你或你的第三方合作伙伴是否从此 App 收集数据？」

**是（Yes）** —— 我们收集账号身份、宠物档案与照片。但下一问的关键分叉是「是否用于追踪」。

## 第 2 问：「你是否使用此数据来追踪用户？」

**否（No）** —— 我们不投放广告、不做跨 App/跨站点追踪、不出售数据、无广告 SDK。
（代码实证：`APP/package.json` 无任何分析/广告 SDK；站点侧的 GA4 只用于营销站，不在 App 内。）

---

## 第 3 问：勾选收集的数据类型（只勾下面这些，**不要多勾**）

| 类别 | 具体项 | 是否关联身份 | 用途 | 依据 |
|---|---|---|---|---|
| **联系信息 Contact Info** | **电子邮件地址 Email Address** | **是（关联）** | App 功能 | Apple 登录返回的邮箱，用于身份与账号 |
| **联系信息 Contact Info** | **姓名 Name** | **是（关联）** | App 功能 | `display_name`（家庭里显示给协作者看） |
| **用户内容 User Content** | **照片或视频 Photos or Videos** | **是（关联）** | App 功能 | 宠物照片，存私有 R2 桶、签名链接访问 |
| **用户内容 User Content** | **其他用户内容 Other User Content** | **是（关联）** | App 功能 | 宠物档案、照护记录、备注等 |
| **标识符 Identifiers** | **用户 ID User ID** | **是（关联）** | App 功能 | 账号内部 ID |

**不要勾**（我们没有）：
- 健康与健身（**不勾**——我们记的是宠物健康，**不是用户的健康数据**；这是最容易勾错的一项）
- 财务信息（**不勾**——支付走 Lemon Squeezy 网页，App 内无购买、不收集支付信息）
- 位置、通讯录、浏览历史、搜索历史、诊断、使用数据（**都不勾**）
- 设备 ID（**不勾**——推送令牌是 APNs 设备令牌，Apple 归为 App 功能所必需，且登出即删）

> **关于「使用数据 Usage Data」为什么不勾**：App 内没有分析 SDK、没有埋点上报。
> 唯一的上报是 APNs 推送与邮件，属功能性，不构成「使用数据」收集。

## 第 4 问：每一类的用途（Purpose）与关联性

逐项：
- **用途**：只勾 **App 功能（App Functionality）**。其余（分析、广告、个性化、开发者沟通等）**全不勾**。
- **是否与用户身份关联（Linked to You）**：**全部选「是」**（邮箱、姓名、照片、其他内容、用户 ID 都能定位到账号）。
- **是否用于追踪（Used for Tracking）**：**全部选「否」**。

## 提交前自查（三条）

1. **与隐私政策一致**：`www.joinplanet.pet/privacy` 第 2 节列的数据项 = 上表五项，不多不少。
2. **与 App 实际行为一致**：Apple 登录（邮箱/姓名）、宠物记录与照片（用户内容）、内部用户 ID。
3. **没有漏网的第三方 SDK**：`APP/package.json` 依赖清单里没有任何分析/广告/归因 SDK（这点审得很严）。
