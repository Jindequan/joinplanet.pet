# Planet Web Design System

Web 端与 APP 共享同一组产品原则：温暖但不幼稚、先行动再记录、共享清晰、状态可恢复。当前冻结的 Web 实现是 `mobile-v3/`（迁移期只读）；原生 App 在 `APP/` 重建，对照该基准，不另起一套品牌语言。

## 视觉语言

- **色彩**：森林绿负责空间、主要导航和正向行动（完成、添加、记录、确认），珊瑚色只负责逾期、危险、删除和错误，鼠尾草绿负责完成/安全状态，暖纸色负责内容层级；颜色不能是唯一状态信号。
- **排版**：Manrope 用于标题和关键数字，DM Sans 用于正文，DM Mono 只用于日期、状态和系统标签。
- **形状**：控件使用 radius-sm/md，内容卡片使用 radius-lg，Hero / 弹层使用 radius-xl；胶囊只用于筛选和短状态。
- **层级**：卡片使用边框 + 轻阴影，浮层才使用大阴影。页面背景保持安静，让 Today 的照护行动成为视觉焦点。
- **图像**：宠物/家庭图片用于建立情绪和识别，不承载关键文字；所有关键操作仍使用真实文本和图标。

## 页面契约

每个页面只能有一个主标题和一个主 CTA，并且必须覆盖 loading、empty、error、success 四类状态。当前 scope（All / Family / Pet）必须在顶部可见。破坏性操作必须使用确认弹层或可恢复反馈。

## 动效契约

- 交互反馈 140ms 左右；页面进入 220–550ms，使用 opacity / translate / 微小 scale。
- 动效只表达层级和反馈，不让用户等待动画完成。
- 卡片 hover 只抬升 1–4px；按钮按下使用轻微缩放；Today Hero 使用非常克制的漂移装饰。
- prefers-reduced-motion: reduce 下保留状态变化，移除循环动画和过渡。

实现入口是 `APP/src/ui/theme/tokens.ts`、`APP/src/ui/components/` 和 `APP/src/ui/motion/`；页面模块只能组合这些 token 与基础组件，不应继续散落新的品牌色、阴影和动效曲线。Web 与原生共享 `APP/` 的视觉契约，`mobile-v3/` 只作为冻结的对照样本。

## 视觉锚点与决策来源（2026-09-14）

本轮视觉收束采用三个已确认的产品锚点，只提取可验证的交互原则，不复制界面：

- **Things 3**：用单一下一步、清晰的动作层级和低噪声列表帮助用户立即执行。
- **Apple Health**：用可追溯来源、稳定的状态语义和克制的颜色表达健康信息的可信度。
- **Day One**：用时间分组、事实优先和安静的长期阅读节奏承载记录。

决策落点：字体、颜色、间距、圆角、阴影和动效只写入 `APP/src/ui/theme/tokens.ts`；任务层级来自 Things 3，健康状态来自 Apple Health，时间线节奏来自 Day One。品牌绿用于空间与正向行动，珊瑚色只用于风险/危险；任何颜色都不能单独承担状态含义。品牌图标使用 Planet 作为产品身份，PawPrint 只在宠物语义明确的业务位置出现。
