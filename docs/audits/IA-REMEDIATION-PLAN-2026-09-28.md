## 二、层级与顺序法条（新增立法，全站强制）

**L1 一屏一主**：任一屏同时可见的 featured/全宽主按钮 **≤1**。第二主钮降级为 outline/ghost。

**L2 三层层级**：
- 主（featured / full 宽）——本屏唯一主动作
- 次（outline / ghost / 段头右槽文本链）
- 危险（danger / tint / 纯文本链）——**只允许出现在对象工作区，且永远在同组最末**

**L3 组内顺序固定为「读出 → 执行 → 管理 → 危险」**。同组不得交叉（如管理动作不得插在读出动作之前）。

**L4 跨组顺序按使用频率降序**，不按字母序、不按创建时间序。

**L5 引用不复述**：B 页引用 A 页的事实时，只给「链接 + 最小标识」，**不复制数字与字段**。已立此法的「一个数字只有一个家」是它的子集。

**L6 一个动作一个家**：同一动作全站至多一个**正典入口**（带完整控件）；其他位置只允许「深链跳转」，不得出现同款控件。

**L7 教学为零**：常驻说明句一律删；状态说明仅在三态（只读 / 归档 / 终局）允许，且每屏 ≤1 句。

**L1/L7 的计量单位澄清（2026-09-28 施工中确定，防下轮歧义）**：L1 与 L7 的"屏"按**焦点区域**计量，不按物理屏——与设计系统既有口径一致（`APP/docs/PLANET_APP_DESIGN_SYSTEM.md`「每焦点区域 ≤1 枚主钮」「单卡即决策面允许 hero 主 CTA」）。原因：按物理屏计量会同时判死 Today 的多张焦点卡与请求中心的多张决策卡，并且会把"隐藏了控件却不给解释"推向违例——而后者与 founder 既有标准（禁用/隐藏必须邻近说明）直接冲突。因此 L7 允许**每个焦点区域内 ≤1 句**状态说明。**已在施工中按此口径落地，未出现同区域两句的情况。**

**执法**：以上七条纳入 `check:design` 扫描器可测项（L1/L2 可静态查，L3–L5 需人工复核）。
