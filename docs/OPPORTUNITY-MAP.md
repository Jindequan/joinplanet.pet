# PLANET 真实需求反推与机会清单

> 日期:2026-08-11
> 方法:基于 PLANET-NEEDS-REPORT.md 的结论 + 最新竞品空白验证检索,反推真实需求
> 原则:**诚实 > 乐观**。宁可少列几个真空白,不要硬凑
> 关键修正:这一轮检索推翻了上一轮"多人协作是空白"的判断——Team Pet App 已在做

---

## 摘要:剔除所有陷阱后,PLANET 真正该押注的只有两个点

经过反推和空白验证,大量"看似机会"的方向要么已被竞品覆盖,要么是竞品一个迭代就能追上的非护城河。剔除所有陷阱后,PLANET 真正的结构性机会只有两个:

1. **免注册链接查看 + PDF 优先**(A1 + B4)——共同构成"宠物世界的随时可交接入口"定位。这是唯一同时具备"没人做"和"竞品做不到/抄不了"的点(平台型竞品商业模式依赖账号锁定,改不了)。
2. **11pets 信任崩塌窗口期**(B1 + B2)——趁 11pets 3.3★ 信任崩塌的 12-18 个月,抢"我的数据不会消失 + 一键生成 PDF"心智。是机会窗口,不是永久护城河,要快。

**其他所有方向——多人协作、交接中心、紧急医疗授权、数据所有权叙事——都是辅助。**

---

## 第一部分:真实需求反推

从全部证据反推,被验证为"市场和用户真正需要的"需求如下。

### 需求 1:就诊前的整理工具(主人侧)— 强

**描述:** 主人在焦虑状态下,5 分钟内把分散的记录(照片、聊天、化验单)整理成兽医看得懂的标准化文件。
**证据:** r/VetTech 公开抱怨"客户承诺带病历但不带"(强);r/AskVet 焦虑主人反复问"兽医接不接受信息表"(强);PMC/NIH 2021 被引 191 次研究证明双方重视信息讲义(强)。反向(主人发兽医)研究稀少(中)。
**当前满足:** 11pets 曾提供但更新后"丢失了报告生成能力"——市场出现空缺;Tamadoggo 偏 OCR 工具;GreatPetCare 重型医疗化。**没有竞品把"主人侧 5 分钟整理"作为核心卖点。**

### 需求 2:多人共养的低摩擦协作 — 强需求,但已饱和

**描述:** 同居伴侣 / 多代家庭 / 合租共养中,谁喂了药、谁遛了狗的实时同步。
**证据:** ABC News / Tribeca Therapy / NPR / The Farmer's Dog 集中报道(强);31% 宠物 App 已支持多成员(强);Reddit r/puppy101 活跃讨论(中)。
**⚠️ 关键修正:** **Team Pet App(teampetapp.com)已专门做"家庭共享宠物照护 + 实时更新通知 + 任务分配";TaskNest、OneHaus、Best4Family 做通用家庭任务。需求已被充分满足,PLANET 在这条线上没有结构性空白。**

### 需求 3:临时交接的结构化模板 — 强,但无壁垒

**描述:** 把宠物基础信息、饮食、用药、过敏、紧急联系人按行业标准格式交给临时照护者。
**证据:** TrustedHousesitters / Evaheld / Pet Sitters International 的交接清单已高度标准化(强)。
**当前满足:** Rover、TrustedHousesitters 平台内置但需注册;Vet Record 支持安全链接分享但接收方体验未明确。需求真实但**无技术壁垒,任何人都能照抄模板**。

### 需求 4:老年/慢性病宠物的长期追踪 — 强

**描述:** 7+ 岁宠物和慢性病(心脏病、肾病、关节炎)的长期用药记录、症状波动、生活质量评估。
**证据:** 39%+ 狗年龄 7+(强);Fact.MR 慢性病护理占 2026 老年宠物服务 37%(强);11pets 主打但评分降到 3.3★(强)。
**当前满足:** 11pets 最成熟但**处于失血状态**。这是"做得更好"机会最大的方向。

### 需求 5:数据所有权与跨机构流通 — 中(情绪强,付费意愿未验证)

**描述:** 主人拥有完整病历副本,可跨兽医机构、跨城市、跨国家携带。
**证据:** Reddit r/Pets 多条"被拒绝访问自己宠物病历"(中);11pets 用户抱怨"被锁出无数记录"(中)。
**当前满足:** 11pets 有导出功能;Vet Record 支持链接分享;VetDex 强调跨设备分享。**功能层面已部分满足,但"主人拥有"的品牌叙事没人做。**

### 需求 6:紧急医疗授权 — 弱(疑似空白)

**描述:** 谁被授权在主人联系不上时为宠物做医疗决定。
**证据:** TrustedHousesitters 提供纸质模板(中);未见学术或大规模用户讨论(弱)。
**当前满足:** **没有任何 App 把它做成数字字段。**

## 第二部分:有市场没人做的空白(A 类机会)

### ⭐ A1:免注册链接查看(高把握真空白)

**空白描述:** 接收方(保姆、邻居、急诊兽医、伴侣的同事)无需注册账号、无需下载 App,点击链接即看到宠物完整照护信息。

**为什么没人做:** Rover / Pet Watch / Cloudy / Nomador / PetBae **全部要求注册才能查看**——这些是平台型竞品,商业模式依赖双边市场锁定。**注册是他们的护城河,不是疏忽。** 这正是 PLANET 的机会:不是平台,是工具,不需要锁定接收方。

**PLANET 怎么做:** 把"零摩擦分享"从子功能升级为定位核心。所有分享链接默认免注册只读,带品牌 preview,可撤销,带访问日志。

**为什么这是真护城河:** 平台型竞品(Rover/TrustedHousesitters)**改不了**——他们的商业模式要求接收方注册才能转化为供给方。PLANET 作为工具型产品没有这个约束。这不是"竞品一个迭代能追上",是商业模式层面的结构性差异。

**风险:** 接收方打开率可能低于预期(用户可能直接发微信文字)。但低成本可验证。
**诚实度:** **高**。检索后确实没找到任何宠物 App 明确提供此特性。

### A2:紧急医疗授权数字化字段(中把握)

**空白描述:** 结构化的"医疗决定授权人"字段——主人指定 1-3 人,在联系不上时可代为签署兽医同意书,生成可打印的授权 PDF。

**为什么没人做:** 不是没想到(纸质模板到处都是),是**没人把它数字化**。推测原因:看似小众、法律有效性存疑、不是 onboarding 必填项。

**PLANET 怎么做:** 在 Sitter Instructions 模板里作为 P0 字段,导出 PDF 时单独一页"Emergency Medical Authorization"。

**风险:** 法律有效性因地区而异;用户可能根本不在乎(Phase 0 的 30 天验证窗口内观察不到使用)。
**诚实度:** 中。空白是真的,但**市场是否够大无法在 Phase 0 验证**。建议作为差异化字段保留,但不作为营销重点。

### A3:数据所有权叙事("主人拥有,可随身携带")

**空白描述:** 不是功能空白,是**品牌叙事空白**——没有任何宠物 App 把"你的数据,你拥有,我们只是载体"作为核心定位。

**为什么没人做:** 兽医 App(Banfield/VCA)商业模式依赖数据锁定;GreatPetCare 绑定单一医疗体系;11pets 没意识到这是情绪杠杆。**不是做不到,是没意识到。**

**PLANET 怎么做:** 营销明确"PLANET 不持有你的数据,你是 owner";支持一键导出完整 PDF + 结构化 JSON;明确退出条款。

**⚠️ 诚实警告:** 叙事不是护城河。竞品一个迭代就能加导出功能、改 slogan。**真正价值是叙事背后的用户心智先占,要在竞品反应前快速建立"PLANET = 主人拥有"的联想。** 是否能转化为付费意愿未验证。
**诚实度:** 中。

### ❌ A4:跨场景交接中心(低把握,疑似陷阱)

**空白描述:** 一个统一的交接中心,涵盖兽医就诊 / 保姆寄养 / 急诊 / 旅行的所有交接场景。

**为什么可能是陷阱:** **更可能是因为市场分散没人做。** 用户每次只面对一个场景,不需要"中心化";各场景模板需求差异大(兽医要 PDF,保姆要清单,急诊要医疗授权)。

**建议:** 不做"中心",做**模板库**——根据接收方类型一键生成对应格式。不作为营销主张。
**诚实度:** 低。检索未找到,但更可能是需求分散而非没人做。

## 第三部分:有人做但我能做得更好(B 类机会)

### B1:数据可靠性 vs 11pets(护城河:中,窗口 12-18 个月)

**现状:** 11pets App Store 评分降到 **3.3★**。用户原话:
- "大部分数据没迁移,迁移的数据还乱序了"
- "被锁出无数记录和图片"
- "Android 上宠物档案突然消失"(Facebook 群组多人报告)
- 官方回应"你的数据很安全"——**信任崩塌**

**PLANET 的"更好":**
- Phase 0 起,所有数据**自动定期导出为 PDF + JSON**,用户可下载到本地
- 显式承诺"数据永不消失":即使 PLANET 停服,导出功能保留 6 个月
- 公开数据备份策略(每周异地备份、加密存储)
- 迁移功能发布前做 100 个真实样本测试

**为什么 11pets 不改进:** 不是技术能力问题,是**老产品技术债深、用户基数大不敢大改、优先级在功能而非基础设施**。
**可信度:** 中。11pets 理论上能修,但**信任崩塌后用户不会回来**——这是窗口期,不是永久护城河。

### B2:报告生成 vs 11pets(护城河:中)

**现状:** 11pets 用户原话:"**丢失了给保姆/兽医生成报告的能力**"——一个曾经存在的功能被更新删掉了。

**PLANET 的"更好":**
- Vet Summary 一键 PDF(11pets 失去的能力,PLANET 直接做透)
- 模板针对接收方分支(兽医 PDF / 保姆清单 / 急诊医疗授权单页)
- 含"本次就诊主诉" + 过敏置顶 + 最近驱虫疫苗状态(11pets 缺)

**为什么 11pets 不修复:** 优先级问题——他们在重做 UI 而非补回功能。
**可信度:** 中。竞品一个版本能追上,但 PLANET 抢占"PDF 优先"心智有先发优势。

### B3:迁移可靠性(护城河:弱,但作为获客工具有价值)

**现状:** 同上"迁移灾难"抱怨。
**PLANET 的"更好":** 提供从 11pets / GreatPetCare / 兽医 PDF 的结构化导入工具,迁移前 preview、迁移后 diff。
**可信度:** 弱。**这是基础功能不是护城河**,任何竞品都能做。但作为"从 11pets 流失用户"的获客杠杆有价值。

### B4:PDF 优先 vs 全行业链接优先(护城河:中)

**现状:** 行业普遍做"可分享链接"(Vet Record / GreatPetCare)。但需求报告反推:**兽医不会在诊室扫码看链接,他们要的是 PDF**。

**PLANET 的"更好":** 所有 Summary 默认 PDF 主形态,链接作为辅形态。这是基于真实工作流反推,**不是 UI 偏好,是形态根本不同**。

**为什么竞品不改进:** 他们已投入链接基础设施;PDF 生成涉及排版、字体、多语言、移动端渲染等工程量,非小迭代能完成。
**可信度:** 中。竞品一个大版本能加 PDF 导出,但**做成"5 分钟生成专业 PDF"的体验需要时间打磨**。

     │
  中 ┤   [A3 数据所有权叙事]      [B2 报告生成]
     │   立即做(营销层)          立即做

     │   不做(疑陷阱)
     └──────────────────────────────────────
        低            中            高

**立即做(P0 投入):**
- A1 免注册链接(差异化核心)

- B2 报告生成(填补 11pets 空缺)

- B1 数据可靠性窗口期(需要快速建立口碑,12-18 个月窗口)

**作为字段保留不营销:**
- A2 紧急医疗授权

**不做:**
- A4 跨场景交接中心(疑陷阱)

## 第五部分:最致命的诚实

### 5.1 看似空白实则是陷阱

**陷阱 1:A4 跨场景交接中心。** 看起来是空白,更可能是因为市场分散没人做。用户每次只面对一个场景,"中心化"是产品经理的想象,不是用户需求。**做模板库,不做中心。**

**陷阱 2:"数据所有权"作为功能。** 叙事空白真实,但**功能层面 11pets / Vet Record / VetDex 都有导出**。如果 PLANET 只是把导出做得更好,这是 B3 弱护城河。只有把"主人拥有"做成**品牌人格**才有价值——而这要求持续的内容输出和社群运营,不是一次开发就完成的。

**陷阱 3:多人协作作为核心卖点。** 31% App 已支持 + Team Pet App 专门做这条线。PLANET 在这里没有结构性空白。**协作是基线,不是差异化。**

### 5.2 看似"做得更好"实则竞品一个版本能追上

**非护城河 1:B3 迁移可靠性。** 任何竞品一个迭代都能加。

**非护城河 2:B4 PDF 优先(功能层)。** Vet Record 一个版本就能加 PDF 导出。**PLANET 的真正优势是"5 分钟生成专业 PDF"的体验打磨 + 营销心智先占,不是 PDF 这个功能本身。**

**非护城河 3:B1 数据可靠性(纯技术层)。** 11pets 大版本能修。**PLANET 的窗口是用户信任崩塌后的 12-18 个月,要在窗口期内抢用户,不是技术比拼。**

### 5.3 PLANET 最不该投入的三个方向

| 不该投 | 依据 |
|---|---|
| **病历管理赛道硬碰** | GreatPetCare 已转型覆盖,绑定医疗体系,数据源优势 PLANET 没有 |
| **AI 宠物翻译器/AI 诊断/风险评级** | PetPal 已在"AI 翻译器"噱头上失败;AI 诊断有法律风险且 PRD 明确不做 |
| **通用家庭任务管理** | Team Pet App、TaskNest、OneHaus 已占据,进入是红海 |

### 5.4 最终诚实结论

剔除所有陷阱和非护城河后,PLANET 真正的结构性机会只有两个:

**机会 1:A1 免注册链接 + B4 PDF 优先**——共同构成"**宠物世界的随时可交接入口**"定位。这是 PLANET 唯一同时具备"没人做"和"竞品做不到/抄不了"的点(平台型竞品商业模式依赖账号锁定,改不了)。

**机会 2:B1 + B2 信任窗口期**——11pets 3.3★ 信任崩塌的 12-18 个月,PLANET 抢"我的数据不会消失 + 一键生成 PDF"心智。这是机会窗口,不是永久护城河,要快。

**其他所有方向——多人协作、交接中心、紧急医疗授权、数据所有权叙事——都是辅助。把资源压在前两个点上,Phase 0 才有差异化成立的可能。**
